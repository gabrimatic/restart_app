`restart_app` lets you restart your Flutter app from Dart on Android, iOS, web, macOS, Linux, and Windows.

```dart
import 'package:restart_app/restart_app.dart';

await Restart.restartApp();
```

iOS requires [AppDelegate setup](/product/ios-engine-restart/) to register plugins with each new Flutter engine. For installation and requirements, see the [quickstart](/quickstart/).

## Features

- **Android:** relaunch the main activity or restart the app process, including on Android TV and Fire TV.
- **iOS:** start a new Flutter engine without closing the app.
- **Web:** reload the Flutter app at the same URL or a destination you choose, with JavaScript and WebAssembly support.
- **Desktop:** relaunch macOS and Windows apps or replace the running Linux process.
- **Error handling:** read restart results and check the modes available on each platform.
- **AI agent skills:** install package-specific integration and iOS setup instructions for your coding agent.
