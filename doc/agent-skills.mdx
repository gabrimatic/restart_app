title: Agent skills
description: Install versioned restart_app guidance for your coding agent.
---

`restart_app` 1.9.2 and later bundle two skills with the package. They teach your
coding agent the package API and platform constraints from the version your app
actually resolves.

| Skill | Use it for |
| --- | --- |
| `restart-app-integration` | Restart modes, structured results, saving state, web routes, desktop behavior, background isolates, and verification. |
| `restart-app-ios-engine-restart` | AppDelegate and UIScene setup, replacement engine registration, custom native shells, and iOS failure handling. |

## Install

From your Flutter project root:

```bash
flutter pub get
dart run skills@ get restart_app
```

Select the skills when prompted. To install both without selecting them:

```bash
dart run skills@ get restart_app --all
```

The CLI detects supported agent configuration and installs the skills there.
For a generic Agent Skills setup, select the destination explicitly:

```bash
dart run skills@ get restart_app --all --agent generic
```

This writes to `.agents/skills/` in your project. The iOS skill includes a
`references/host-setup.md` file with both lifecycle examples; keep that file with
the skill when moving it manually.

The `dart run skills@` syntax requires Dart 3.12 or later. The Skills CLI itself
supports Dart 3.10 or later. On Dart 3.10 or 3.11, install and run it with:

```bash
dart pub global activate skills
dart pub global run skills get restart_app
```

These are development tools. Do not add `skills` to your app dependencies or
raise your app's minimum SDK just to bundle these instructions. The plugin's
Dart and Flutter minimum versions are unchanged.

## Updates

After changing the resolved `restart_app` version, run `flutter pub get` and the
skill installation command again. The CLI reports updated skills. Review the
installed changes along with the dependency upgrade.

The CLI reads the package selected by your dependency resolution, including a
path dependency during local development. If no skills are found, check that
`restart_app` is a direct dependency and resolves to 1.9.2 or later. For a custom
agent setup, pass its supported `--agent` value explicitly.

## Scope

Skills provide instructions to your coding agent. They do not configure your
AppDelegate automatically, alter runtime restart behavior, or guarantee that a
restart succeeds. Review generated changes and test on the target platform.

For the packaging convention and CLI details, see Dart's
[package skills guide](https://dart.dev/tools/pub/package-skills).
